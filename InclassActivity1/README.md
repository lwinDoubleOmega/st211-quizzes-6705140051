# In-Class Activity 1: Getting Started with Tests

This activity was introduction to writing simple tests with `pytest`. The first examples check basic Python operations, such as addition, strings, and lists. I also wrote a Roman numeral converter and tested it with examples like `IV`, `XIV`, and `MCMXCIV`.

To run the tests from this folder:

```bash
python -m pytest
```

The main files are `romanNumeral.py` for the converter and `testRoman.py` for its tests. `test_first.py` and `test2.py` contain the introductory examples.
